# TerraTwin

NASA Space Apps Challenge 2026 (Ganja). Earth analogs of the Moon and Mars, built on open NASA data.

- `index.html` — overview and video
- `terraanalog.html` — TerraAnalog Explorer platform
- `presentation.html` — 3D presentation
- `oyun.html` — game "Earth or Mars?"
- `skaner.html` — analog scanner

Data: NASA POWER, NASA PDS (MOLA, LOLA), NOAA ETOPO5, NASA Blue Marble, NASA NSSDC, NASA Image and Video Library; volcanoes from the Smithsonian Global Volcanism Program.
